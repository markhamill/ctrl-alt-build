# Wrestling the DOM: Flexbox, Regex, and SPA Routing

Building a custom static site generator inevitably leads to a standoff with the DOM. Today's sprint was entirely about UI polish and structural integrity—getting the brutalist aesthetic to behave across viewports without relying on bloated component libraries.

### The Duplicate Title Problem

When using `react-markdown` alongside frontmatter, you often end up with a duplicate H1: one generated by the React wrapper reading the YAML, and one inside the markdown body itself. 

Rather than manually editing every single markdown file, I wired up a regex replacement before the markdown pipeline parses the body:

```javascript
{selectedPost.body.trimStart().replace(/^#\s+.*[\r\n]+/, '')}
```

It exclusively targets an H1 at the very start of the string, factoring in potential whitespace. Simple, stateless, and instantly cleans up the render across the entire directory.

### Forcing the Layout

Flexbox is great until it runs out of pixels. When building the article header, the flex containers kept desperately trying to wrap the date and read-time onto two lines to make room for the massive title font.

Sometimes, the best solution isn't to configure flexbox better, but to strip it out entirely. By converting the meta-info block to inline text and aggressively applying `whitespace-nowrap`, the browser is physically forbidden from stacking the text. It snaps the date, the separator dot, and the read time into a perfect, unbreakable horizontal line. 

### Mobile Typography

The "CTRL+ALT+BUILD" logo spans 14 characters without spaces. On a narrow mobile screen, it physically runs out of pixels. Rather than scaling the text down and losing the brutalist impact, I used Tailwind's `md:hidden` breakpoint modifiers on `<br>` tags to cleanly split the title onto two lines specifically for mobile devices, while keeping it a single massive string on desktop.

### Fixing SPA Routing & Scroll Bugs

The final pieces of the puzzle were classic Single Page Application (SPA) routing bugs. 

First, swapping components leaves the user stranded halfway down the page because the browser doesn't automatically reset the scrollbar like it does on a traditional page load. A simple `useEffect` hook tied to the navigation state solves it entirely:

```javascript
useEffect(() => {
  window.scrollTo(0, 0)
}, [selectedPost, activeTab])
```

Second, the URL slugs were originally derived from the physical local filenames (e.g., `006-draft.md`). By mapping the slug generation to the `id` field in the YAML frontmatter instead, the routing engine now enforces a pristine `/#dispatch-006` format, completely decoupled from the local filesystem conventions.
